# 批量数据处理说明

## 概述

`batch_process_data.py` 对 `data/` 目录下各子目录中的 Excel 和 CSV 文件进行统一转换，生成规范的宽表 CSV 文件，输出到 `output/` 目录。

处理逻辑参考 `示例脚本/` 中的脚本，并根据实际数据结构进行了适配。

## 运行方式

```bash
python batch_process_data.py
```

需要安装：`pandas`、`openpyxl`

```bash
pip install pandas openpyxl
```

## 特殊映射

- **开停状态**（日前机组开机安排）：停机→0，开机→1，其他→2
- **是否越限**（实时输电断面约束及阻塞）：否→0，是→1，其他→2
- **当日测试结果**（省调煤电机组最大出力认定考核公示）：不合格→0，合格→1，不确定→2，其他→3

## 文件大小限制

单文件超过 5MB 时自动拆分为多个文件（如 `xxx_part1.csv`、`xxx_part2.csv`）。

## 时间格式

统一为 `YYYY-MM-DD HH:MM:SS.000`，如：`2026-01-01 00:15:00.000`。

## 编码

输出 CSV 使用 UTF-8 编码。
